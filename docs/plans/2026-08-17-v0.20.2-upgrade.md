# Hermes Agent v0.20.2 Upgrade Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task.

**Goal:** Move the fork deployment from stable upstream v2026.7.20 (v0.19.0) to v2026.8.16 (v0.20.2) while preserving the hardened arbitrary-UID rootless image contract.

**Architecture:** Keep `main` identical to the stable upstream tag and rebase each overlay branch onto that tag. **Tech Stack:** Git overlay branches, Docker multi-stage builds, POSIX shell, pytest contract tests, GitHub Actions.
